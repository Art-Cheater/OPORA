# Процесс разработки

Прод не должен быть веткой разработки.

1. Фичи — в отдельных ветках от `main` (или от `develop`, если заведёте).
2. В `main` — только merge через pull request, не прямой push с ноутбука.
3. **Коммиты** — тег + понятный заголовок, при необходимости описание ниже:

   ```
   [обучение] Тур по разделам с подсветкой кнопок и форм

   Автопоказ только при первом входе. В каждом модуле —
   фильтры, создание, поля и сохранение.
   ```

   Теги: `обучение`, `мессенджер`, `обращения`, `заявки`, `еис`, `договора`,
   `документы`, `роли`, `инфра`, `фикс`, `ui`, `docs`.

4. CI гоняет тесты на SQLite и на PostgreSQL. Красный CI не мержить.
5. Деплой с `main` на self-hosted runner (**Debian 13**, каталог `/opt/opora`).
