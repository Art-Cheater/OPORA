# IRZ · Полноэкранная карта (экран)

Страница `/irz/map-display` — карта состояния сети ATM21 для настенного экрана
или телевизора в диспетчерской. Только просмотр: без боковой панели, topbar,
редактирования и ручного опроса.

## Что показывает

- Шапка «IRZ · Состояние сети» со счётчиками Горит / Не горит / Проблема /
  Критическая (условия — в [`IRZ_MERCURY.md`](IRZ_MERCURY.md#статус-освещения)).
- Маркер IRZ: лампа статуса (зелёная — горит, серая — не горит, жёлтая —
  проблема, красная — критическая) над плашкой с названием ШУНО. Плашка
  розовая для «ИП…», серо-белая для «ПП…», светло-зелёная для остальных.
- Переключатели «Подписи» и «Опоры» (запоминаются в браузере экрана). IRZ
  показываются всегда; треугольники опор — с zoom 15.
- Подвал: легенда ИП/ПП, всего устройств, ATM21 online/offline, без координат,
  «Обновлено ЧЧ:ММ».
- Данные обновляются запросом `GET /irz/api/map` каждые
  `IRZ_MAP_DISPLAY_REFRESH_SECONDS` секунд (по умолчанию 20, допустимо 15–30).
  Страница не перезагружается; при потере связи показывается предупреждение,
  карта остаётся с последними данными.
- Во всплывающей карточке кнопка «Подробнее» есть только у пользователей с
  правом `irz.view`.

Устройства без координат на карте не отображаются; координаты задаются в
карточке устройства (`/irz/<id>`, право `irz.edit`).

## Права

| Право | Что даёт |
|---|---|
| `irz.map_display` | `/irz/map-display`, `GET /irz/api/map` и слой опор `GET /irz/poles/map.json` |
| `irz.view` | раздел IRZ целиком: карта со списком, карточки устройств |
| `irz.edit` | название, адрес, координаты |
| `irz.poll` | ручной опрос счётчика, журналы событий |

Права назначаются в разделе «Роли» (модуль «IRZ · Мониторинг»). Администратор
получает все права автоматически.

## Роль экрана «Карта IRZ (экран)»

Системная роль `irz_display` содержит только `irz.map_display`. Пользователь с
такой ролью:

- после входа сразу попадает на `/irz/map-display`;
- не видит и не может открыть остальные разделы (сервер отвечает 403);
- не получает право на личные документы, которое выдаётся остальным ролям.

Настройка экрана:

1. «Сотрудники» → создать учётную запись, например «Карта», с отдельным
   адресом входа и надёжным паролем.
2. Назначить роль «Карта IRZ (экран)».
3. На компьютере экрана открыть систему в браузере, войти с отметкой
   «Запомнить меня». Срок cookie задаётся `REMEMBER_COOKIE_DAYS`
   (по умолчанию 30 дней).
4. Запустить браузер в режиме киоска, например
   `chromium --kiosk https://<адрес системы>/irz/map-display`.

Доступ к карте только после входа. Ссылок с токеном в URL нет и не будет:
постоянный секрет в адресе легко утекает через историю, логи и скриншоты.
Чтобы отключить экран, достаточно заблокировать учётную запись или сменить
пароль.

## Отдельный поддомен `map.<домен>`

Карту можно вынести на отдельный поддомен, где nginx пропускает только вход,
статику и два адреса карты. Cookie сессии привязаны к хосту, поэтому на
поддомене нужен отдельный вход, а сессия основного сайта там не действует.

Пример server-блока. `map.example.com` и пути к сертификатам замените на свои;
upstream `gunicorn` и путь статики совпадают с `docker/nginx.conf`.

```nginx
server {
    listen 443 ssl;
    http2 on;
    server_name map.example.com;

    ssl_certificate     /etc/nginx/certs/map.example.com/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/map.example.com/privkey.pem;

    location = / {
        return 302 /irz/map-display;
    }

    location /static/ {
        alias /usr/share/nginx/html/static/;
        expires 30d;
        add_header Cache-Control "public, max-age=2592000, immutable";
        access_log off;
    }

    location = /favicon.ico {
        alias /usr/share/nginx/html/static/favicon.ico;
        access_log off;
    }

    location ~ ^/(auth/|irz/map-display$|irz/api/map$|service-worker\.js$) {
        proxy_pass http://gunicorn;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location / {
        return 404;
    }
}

server {
    listen 80;
    server_name map.example.com;
    return 301 https://$host$request_uri;
}
```

Замечания:

- Ограничение nginx — дополнительный слой. Авторизация и права по-прежнему
  проверяются приложением на каждом запросе.
- Кнопка «Подробнее» ведёт на `/irz/<id>`, который на поддомене закрыт. Если
  экран должен открывать карточки, добавьте `irz/` в регулярное выражение
  (без права `irz.view` сервер всё равно ответит 403) или откройте карточку на
  основном адресе.
- При необходимости ограничьте поддомен сетью диспетчерской через
  `allow <подсеть>; deny all;`.
