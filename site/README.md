# Кировсвет — сайт службы наружного освещения (пример)

Демо-сайт по документу «Кировсвет: анализ и концепция сайта». Главная задача — чтобы человек за минуту и без регистрации сообщил о неисправном фонаре и мог проверить статус заявки.

Рабочий домен: **kirovsvet.truthqwark.ru**.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/
npm run preview  # проверка сборки: http://localhost:4321
npm run check    # проверка типов TypeScript (astro check)
npm run validate # проверка HTML всех страниц после сборки (html-validate)
```

Node 20+ (проверено на 24). Сборка — чистый статический HTML/CSS/JS, сервер приложений не нужен.

## Страницы

| Адрес | Что на ней |
| --- | --- |
| `/` | Первый экран с кнопкой заявки, телефоном и проверкой номера; «Сегодня»; известные аварии; «Чей это фонарь»; цифры; новости |
| `/soobshit/` | Заявка в 4 шага: что случилось → где (карта, «Я здесь», подсказки улиц, номер опоры) → фото → контакты |
| `/zayavka/?n=…&k=…` | Статус заявки: ячейки «загораются», история, кнопки «Спасибо, горит» / «Всё ещё не горит» (только по ссылке с ключом) |
| `/karta/` | Аварии, заявки, плановые отключения, стройки на карте + то же списком |
| `/grafik/` | Включение и отключение сегодня и на 14 дней, часы горения по месяцам |
| `/chey-fonar/` | Кто отвечает за улицы, дворы, светофоры, парки и куда звонить |
| `/voprosy/` | 12 вопросов, сроки ремонта, наклейки с QR-кодом |
| `/stroitelstvo/` | План на год, готовые объекты, как попасть в программу |
| `/novosti/` | Новости и страницы новостей |
| `/o-sluzhbe/`, `/kontakty/`, `/politika/` | О службе и реквизиты, контакты с картой, политика обработки данных |
| `/dispetcher/` | Демо панели диспетчера: фильтры, смена статусов, карта, выгрузка CSV |

Что ещё сделано по ТЗ: тёмная тема по настройке телефона, версия для слабовидящих (ГОСТ Р 52872-2019: шрифт 100/125/150 %, схемы Ч/Б, Б/Ч, синяя, без картинок, интервал), закреплённая кнопка «Сообщить» на телефоне, опасные случаи с красной плашкой «не подходите ближе 8 метров», поиск дублей в радиусе 50 м, черновик формы, сжатие фото на телефоне, лимит 5 заявок в сутки с устройства, проверка границ города, QR-ссылка вида `/soobshit/?pole=17-034&lat=…&lon=…`.

## Что это пока демо

- Все телефоны `00-00-0Х`, почта `.example`, цифры, сроки, реквизиты — выдуманы (как в документе). Меняются в `src/data/site.ts`.
- `SITE.demo = true` включает плашку «Демо-версия», `noindex` и заглушку `robots.txt`. При запуске: `demo: false` и новый `public/robots.txt` (текст внутри файла).
- Заявки хранятся только в `localStorage` браузера (`src/lib/tickets.ts`). В службу ничего не уходит.
- Карта — Leaflet + OpenStreetMap. По ТЗ в рабочей версии — Яндекс Карты, геокодер и SmartCaptcha (`src/lib/map.ts`, место под капчу отмечено в `src/scripts/report.ts`).
- График включения считается по закату и восходу для Кирова (+15 мин / −15 мин, `src/lib/sun.ts`). Реальные смещения сверить с диспетчерской.
- Координаты улиц получены разово из OpenStreetMap (`npm run geo` → `src/data/geo.json`).

## Бэкенд заявок: что подключить

Страницы вызывают только функции из `src/lib/tickets.ts`. Их тела заменяются на запросы к API, интерфейс остаётся:

| Функция | Запрос |
| --- | --- |
| `createTicket(draft)` | `POST /api/tickets` → `{ number, key, term, emergency }` (с токеном SmartCaptcha) |
| `getTicket(number)` | `GET /api/tickets/{number}?key=…` — без ключа только публичные поля: тип, адрес, статус, история |
| `findNearbyOpen(lat, lon)` | `GET /api/tickets/nearby?lat=…&lon=…&radius=50` |
| `addAlsoSeen(number)` | `POST /api/tickets/{number}/also-seen` |
| `feedback(number, key, stillBroken)` | `POST /api/tickets/{number}/feedback` |
| `listTickets`, `setStatus`, `setShowOnHome` | `GET/PATCH /api/admin/tickets…` — только для диспетчеров, с авторизацией |

Требования из ТЗ: сервер и база в России (152-ФЗ), контакты заявителя никогда не отдаются публичным методам, ключ в ссылке — случайный, чтобы чужую заявку нельзя было открыть перебором номеров.

## Дизайн-система

`design-system/kirovsvet/MASTER.md` — единый источник правил: токены брендбука, типографика, движение, правила доступности и чек-лист. Собрана навыком ui-ux-pro-max (стиль «Accessible & Ethical» для госсервисов) и приведена к брендбуку. Страничные исключения — в `design-system/kirovsvet/pages/`.

По брендбуку фото на рабочем сайте должны быть настоящими — сгенерированные стоят как заглушки. После замены исходников: `npm run images`. Иконки вкладки («Пиксель К») — `npm run brand`.

## Выкладка

Сайт собирается в контейнер `public-site` вместе с «Опорой»: `scripts/deploy.sh` поднимает его на каждом деплое. Снаружи его отдаёт общий nginx.

- Домен: `kirovsvet.truthqwark.ru`. Пока сертификата нет, сайт открывается по HTTP. Когда DNS указывает на сервер, deploy выпускает сертификат и включает HTTPS.
- Карта и блок «Где сейчас нет света» берут открытые заявки из «Опоры» по адресу `/api/map.json`. В ответ входят только адрес и статус.
- Локально контейнер слушает `127.0.0.1:8090`.
- Заголовки CSP и геолокации — в `nginx.container.conf`.
- Демо не индексируется, пока `SITE.demo = true` (плашка, `noindex`, `public/robots.txt`).

Исходники картинок из Higgsfield в git не входят: готовые файлы для сборки уже лежат в `src/assets/img`.
