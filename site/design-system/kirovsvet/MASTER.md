# Дизайн-система «Кировсвет» — MASTER (v3 «Бенто»)

> Выбрано пользователем из четырёх вариантов (`/varianty/`: A — минимализм, B — ночное стекло, **C — бенто**, D — необрутализм).
> Стиль из ui-ux-pro-max: **Bento Box Grid** + Accessible & Ethical. Бренд: «Вятская ночь» + «Натриевый свет», Montserrat + Golos Text.
> Страничные исключения — в `design-system/kirovsvet/pages/<page>.md`.

## Цвета

| Роль | HEX | Токен | Где |
| --- | --- | --- | --- |
| Фон страницы | `#F5F5F7` | `--bg` | Везде |
| Плитки | `#FFFFFF` | `--surface` | Карточки без рамок и теней |
| Текст | `#1D1D1F` | `--text` | Основной |
| Вторичный текст | `#6E6E73` | `--muted` | ≥ 4,5:1 на белом и на фоне (не `#86868B`) |
| Вятская ночь | `#14213D` | `--night` | Тёмные плитки: «Сегодня», аварии на карте, цифры |
| Натриевый свет | `#FFB81C` | `--sodium` | Одно действие на экране, огоньки |
| Ссылки | `#1F5FBF` | `--link` | |
| Авария / Горит | `#C81E36` / `#1F8A5F` | `--alarm` / `--ok` | Только статусы, всегда с текстом |

Тёмная тема (по настройке телефона): фон `#000`, плитки `#1C1C1E`, текст `#F5F5F7`, вторичный `#A1A1A6`.

## Типографика

Основной текст 16 px, межстрочный 1,55. H1 до 56 px (Montserrat 700, трекинг −0,04em), H2 до 32, H3 20. Подписи 13–14 px. Номера и время — `tabular-nums`.

## Форма

- Плитки: белые, скругление 26 px, без рамок и теней; при наведении — лёгкое увеличение (1,012), выключено при `prefers-reduced-motion`.
- Сетка главной: 4 колонки × строки по 210 px; фото-плитка 2×2, «Сегодня», проверка заявки, аварии, «Чей фонарь», цифры 2×1, бригады 2×1. На телефоне — 2 колонки.
- Кнопки — «таблетки» 44 px (главные 48 px). Поля — 48 px, скругление 14 px.
- Шапка 56 px, полупрозрачная с размытием; меню 14 px по центру; телефон, значок «Для слабовидящих», маленькая кнопка «Сообщить».
- Подвал — светлый, мелкий текст колонками; над ним плитка помощи «Позвоните — оформим за вас» (одинаково на всех страницах, WCAG 3.2.6).

## Доступность (обязательно)

Контраст ≥ 4,5:1; цели нажатия ≥ 44 px; видимый фокус (кольцо + жёлтый ореол); ошибки у полей с `aria-describedby` и `role="alert"`; фокус не прячется под закреплённой панелью; версия для слабовидящих по ГОСТ Р 52872-2019; без мигания; повторяющиеся анимации ≤ 5 с.

## Запрещено

Вторая жёлтая кнопка на экране; рамки и тени у плиток; мелкий капс; `#86868B` для текста; красный и зелёный для украшения.
